Postřehy

Architektura pro stabilitu.

Komplexita je rozdělená do malých modulů: každý má svůj stav, render funkci a bezpečné ukládání. Když prohlížeč něco nepodporuje, web má fallback.

1. Bez externích CDN

Žádné frameworky, fonty, ikony ani obrázky z internetu. Soubor otevřeš i offline.

2. Stav v localStorage

Úkoly, poznámky, kontakty i nastavení přežijí refresh. Při chybě parsování se načte bezpečný default.

3. Přístupnost

Semantické sekce, skip link, aria popisky, ovládání klávesnicí a čitelné focus stavy.

4. Modulární JavaScript

Jeden uzavřený scope, žádné globální proměnné kromě DOM API, opatrné selektory a guardy.
